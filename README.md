## 📊 Grade de Módulos e Pontuação (Mínimo: 14 Pontos)

Para viabilizar o uso do **Next.js/React** no frontend e garantir uma entrega segura dentro do prazo, focaremos na receita de módulos sem Blockchain:

1. **Framework Frontend + Backend (Node/React/Next.js):** 2 pontos
2. **Uso de ORM no Banco de Dados (PostgreSQL):** 1 ponto
3. **Módulo de Jogo Web Completo (Godot via WebAssembly):** 2 pontos
4. **Jogadores Remotos (Multiplayer via WebSockets):** 2 pontos
5. **Inimigo de IA (Modo treino/singleplayer na Godot):** 2 pontos
6. **Gerenciamento de Usuário Padrão (Perfil/Amigos):** 2 pontos
7. **Autenticação Remota (OAuth - Login 42):** 1 ponto
8. **Histórico de Partidas e Estatísticas:** 1 ponto
9. **Sistema de Torneio (Chaveamento/Brackets):** 1 ponto

🔥 **Total Planejado:** **14 pontos exatos.**

## 🔒 Bônus de Cybersecurity (Validação Extra)
*   **WAF (Web Application Firewall):** Proteção do backend contra ataques como SQL Injection e XSS.
*   **Segurança Padrão:** Criptografia rígida de senhas (Hashing/Salting) e Autenticação em Dois Fatores (2FA).
