# Para testar com front em dev

- iniciar server no teminal 1:

```
make server

```

- iniciar frontend no terminal 2:

```
cd frontend/
npm run dev

```

# Para testar com front integrado ao docker / backend / nginx


```
cd docker
make up

```

- Acessar:

```
https://localhost:8443/

```


- para encerrar tudo:


```

make down

```
